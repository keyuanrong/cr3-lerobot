# 远程 Pi0 RTC-V1 推理开关

## 目标

在现有 CR3 远程 Pi0 推理上增加 RTC-V1，以降低远程动作块交接产生的抖动；默认推理行为不变，便于同一模型对比。

## 设计

1. 服务端通过 `--rtc-enabled` 创建 `RTCConfig`，将未消耗的上一模型动作块传给 `PI0Policy.predict_action_chunk`。
2. 服务端保存的是 Pi0 后处理之前的模型动作，避免把符号修正、绝对重锚、限幅后的机器人命令错误地作为 RTC 前缀。
3. 客户端在下一个请求中报告上一块已执行帧数和预估延迟帧数；若因延迟丢弃整个响应，则显式清除服务端历史。
4. RTC 启用时只允许本地 `replace` 队列，禁止再叠加旧的 `ensemble`，保证测试变量单一。

## 验证

- 协议单元测试：首块无前缀，后续块只使用未消耗模型动作；禁用 RTC 时不传推理参数。
- 语法与命令行检查：客户端、服务端可编译，`--help` 列出 RTC 参数。
- 真机前先用不带 `--execute` 的 dry-run 确认两端日志都显示 RTC 已启用；随后在安全工作空间中单独测试红色任务。
